FGD DASHBOARD · UPLOAD PASSWORD SETUP (OWNER ONLY)
What this page does
  1. You paste the GitHub access key (fine-grained token, Contents: Read and write on this repository only).
  2. You choose an upload password for the shift engineers.
  3. The key is locked (AES-256 encrypted) with that password and saved in access-keys.json. Only someone who types the password can unlock it and upload.
  4. The access key and the password themselves are never stored anywhere in plain form.
